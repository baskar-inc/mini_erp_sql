# Oracle SQL – Mini HR Database

> **Oracle SQL Foundation Project**

A focused hands-on Oracle SQL project demonstrating relational database design and enterprise-style querying through a small Human Resources data model.

## Project Scope

- Relational table design
- Primary and foreign keys
- Unique and check constraints
- Master data
- Sample transaction-style data
- SQL validation and querying
- Oracle-compatible SQL practice

## Data Model

The core model contains:

- `departments`
- `employees`

Employees are associated with departments through a foreign-key relationship.

## Technical Stack

- Oracle Database
- SQL
- Oracle SQL Developer / Oracle Live SQL

## Purpose

This project demonstrates the SQL foundation used for larger ERP-oriented database work.

The advanced portfolio project is [Oracle Procurement & Invoice Management System](https://github.com/baskar-inc/oracle-procurement-invoice-management-system).
